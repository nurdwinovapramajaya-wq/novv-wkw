Jaringan Komputer

Bidang Keahlian • Teknik Jaringan Komputer

Jaringan komputer adalah sistem yang menghubungkan dua atau lebih perangkat komputer agar dapat saling berkomunikasi dan berbagi sumber daya. Jaringan memungkinkan pertukaran data, penggunaan perangkat bersama seperti printer, serta akses internet yang lebih efisien.

Jenis-Jenis Jaringan

  • LAN (Local Area Network) — jaringan untuk area kecil seperti sekolah atau kantor.
  • MAN (Metropolitan Area Network) — jaringan untuk area kota.
  • WAN (Wide Area Network) — jaringan untuk area luas antar negara.
  • Internet — jaringan global yang menghubungkan seluruh dunia.

Komponen Utama

Dalam membangun jaringan, dibutuhkan beberapa komponen seperti router, switch, kabel, dan perangkat wireless access point. Masing-masing memiliki fungsi berbeda untuk memastikan data dapat mengalir dengan lancar.

Routing dan Switching

Routing adalah proses menentukan jalur terbaik untuk mengirim data, sedangkan switching adalah proses mengarahkan data ke perangkat yang tepat dalam jaringan lokal. Keduanya adalah konsep dasar yang wajib dipahami seorang network engineer.

Mengapa Saya Mempelajari Ini?

Saya mempelajari jaringan komputer karena saya percaya bahwa dunia modern ini bergantung pada konektivitas. Dengan memahami jaringan, saya dapat ikut berkontribusi dalam membangun infrastruktur digital yang lebih baik.

Konfigurasi Jaringan

Bidang Keahlian • Router & Access Point

Konfigurasi jaringan adalah proses pengaturan perangkat jaringan agar dapat berfungsi dengan baik. Ini meliputi pengaturan router, access point, switch, dan perangkat lain agar dapat saling terhubung dan berkomunikasi.

Perangkat yang Sering Dikonfigurasi

  • Router — mengatur lalu lintas data antar jaringan.
  • Access Point — menyediakan koneksi nirkabel (WiFi).
  • Switch — menghubungkan beberapa perangkat dalam satu jaringan lokal.
  • Firewall — melindungi jaringan dari akses yang tidak diinginkan.

Hal yang Dipelajari

Dalam konfigurasi jaringan, saya belajar tentang pengalamatan IP, subnetting, routing, VLAN, dan pengaturan keamanan dasar. Semua ini adalah pondasi yang penting untuk membangun jaringan yang stabil dan aman.

Tools yang Digunakan

Beberapa tools yang sering saya gunakan untuk simulasi dan praktik antara lain MikroTik, Cisco Packet Tracer, dan perangkat jaringan asli di laboratorium sekolah.

Mengapa Ini Penting?

Tanpa konfigurasi yang tepat, jaringan tidak akan berjalan dengan optimal. Kesalahan kecil dalam konfigurasi bisa menyebabkan seluruh jaringan bermasalah. Karena itu, ketelitian dan pemahaman konsep sangat penting.

Web Development

Bidang Keahlian • HTML, CSS, JavaScript

Web development adalah proses membangun dan memelihara website. Ini mencakup berbagai aspek, mulai dari tampilan (frontend) hingga logika di balik layar (backend).

Tiga Pondasi Utama

  • HTML — struktur dasar halaman web.
  • CSS — mengatur tampilan dan desain.
  • JavaScript — menambahkan interaksi dan logika.

Apa yang Saya Pelajari

Saya mempelajari dasar-dasar HTML dan CSS untuk membangun tampilan website yang rapi dan responsif. Selain itu, saya juga belajar JavaScript untuk menambahkan interaksi pada halaman web.

Praktik yang Dilakukan

Saya membuat beberapa proyek kecil seperti website profil, halaman portofolio, dan eksperimen dengan animasi CSS. Website yang sedang Anda lihat ini adalah salah satu hasil dari pembelajaran saya.

Visi ke Depan

Ke depannya, saya ingin mendalami frontend framework seperti React atau Vue, serta backend seperti Node.js, agar dapat membangun aplikasi web yang lebih kompleks dan bermanfaat.

Cyber Security

Bidang Keahlian • Keamanan Jaringan & Data

Cyber security adalah praktik melindungi sistem, jaringan, dan data dari serangan digital. Di era yang serba terhubung seperti sekarang, keamanan siber menjadi salah satu bidang yang paling penting dan terus berkembang.

Ancaman Umum

  • Malware — perangkat lunak berbahaya seperti virus dan trojan.
  • Phishing — penipuan untuk mencuri data pribadi.
  • DDoS — serangan yang membuat server tidak bisa diakses.
  • SQL Injection — serangan pada database website.

Dasar-Dasar yang Dipelajari

Saya mempelajari konsep dasar keamanan seperti enkripsi, autentikasi, firewall, dan manajemen akses. Saya juga belajar bagaimana mengidentifikasi celah keamanan dan cara menanganinya.

Dalam mempelajari keamanan siber, etika adalah hal utama. Semua pengetahuan yang saya pelajari digunakan untuk tujuan yang baik — melindungi, bukan merusak.
